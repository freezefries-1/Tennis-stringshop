# Project instructions

## Design direction
For every HTML design in this project, use the **SportCraft Design System** bound at
`_ds/sportcraft-design-system-1803c2a9-3a3c-4732-aadf-c605d1f21fa4/` as the binding
visual reference.

- Load its token stylesheets + `styles.css` + `_ds_bundle.js` on every page, and compose
  with the components exported on `window.SportCraftDesignSystem_1803c2` rather than
  restyling raw HTML.
- Check `templates/marketing-page/` and `templates/workshop-screen/` first; copy one as a
  starting point when it matches the request.
- Follow the system's guide (colors, type, spacing, voice) — no invented colors, fonts, or
  components. Court green is structural, optic yellow at most once per view, max two
  background colors per screen, flat backgrounds (no gradients), no emoji.
- Copy: sentence case, plain and specific, numbers over adjectives, verb + object buttons.

Do not ask which visual style to use — this is the answer.
